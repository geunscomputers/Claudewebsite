# Nieuwe Website — Uitleg over Claude

Een infosite die uitlegt wat Claude is en wat je ermee kan doen.

## Stack

Plain HTML, CSS en JavaScript — geen build-stap nodig.

## Lokaal bekijken

Open `index.html` in een browser, of gebruik de Live Preview van Cursor.

## Structuur

```
.
├── index.html          # Wat is Claude?
├── functies.html       # Wat kan Claude?
├── tips.html           # Tips & voorbeelden
├── contact.html        # Over deze site
├── css/
│   └── styles.css      # Gedeelde Apple-stijl
└── js/
    └── main.js         # Interactiviteit
```
